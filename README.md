# NumPy & Pandas Data Projects

A collection of data analysis and preprocessing projects built with NumPy and Pandas — taking messy, real-world-style datasets and transforming them into clean, ML-ready data through practical exercises.

## Projects

| Project | Description |
|---|---|
| [Developer Log Analysis](./developer-log-analysis/main.py) | Cleans and analyzes messy developer log data, transforming it into a structured, ML-ready format. |
| [Developer Productivity Tracker](./developer-productivity-tracker/main.py) | Uses Pandas to track and analyze developer productivity metrics. |
| [Wellness AI Preprocessing](./wellness-ai-preprocessing/main.py) | A NumPy-based preprocessing challenge preparing wellness data for machine learning models. |
| [Smart City Fitness Analytics](./smart-city-fitness-analytics/main.py) | Analyzes fitness and activity data in a smart-city context using data manipulation techniques. |

## Tech Stack

- Python 3
- NumPy
- Pandas

## Getting Started

Each project can be run directly with Python 3:

```bash
cd developer-log-analysis
python3 main.py
```

Install dependencies first if needed:
```bash
pip install numpy pandas
```

## About

This repository reflects hands-on practice with NumPy and Pandas — focused on real-world data wrangling skills like cleaning messy data, handling missing values, and preparing datasets for analysis or machine learning.
